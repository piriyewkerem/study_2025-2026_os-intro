# Цель работы

Изучение основ программирования в оболочке ОС UNIX, создание командных файлов с использованием логических управляющих конструкций и циклов.

# Задание

1. Создание рабочего каталога `~/lab13`.
2. Разработка программы на C `check_num.c`.
3. Создание bash-скрипта `test_num.sh` для анализа кодов возврата.
4. Разработка скрипта `files.sh` для работы с временными файлами.
5. Разработка скрипта `backup_recent.sh` для архивации файлов.
